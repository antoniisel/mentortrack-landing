# MentorTrack — Landing Page Plan

## 0. Контекст и привязка к ДЗ-12

**Продукт:** MentorTrack — SaaS-платформа для индивидуальных IT-менторов с AI-ассистентом. Единое рабочее пространство (профиль ученика, AI-черновик фидбека, проактивный мониторинг дропаута, AI-генерация плана обучения, pre-meeting summary). Подписка: Starter 1 490 ₽ / Pro 2 990 ₽ / Team 7 990 ₽.

**Что требует ДЗ-9 / неделя 12 (рубрика оценивания):**

| Критерий | Балл | Где закрываем |
|---|---|---|
| Лендинг ≥ 5 логических блоков | 3 | §5: 11 блоков |
| Каждый блок содержит актуальный контент (фото/видео/текст) | 3 | §6: контент по каждому блоку |
| Блок с макетами продукта (ключевой сценарий) | 2 | §7: блок «Как это работает» — 3 экрана |
| Стоимость + модель покупки + decision-driving элементы | 2 | §8: блок «Тарифы» |

**Сценарии продукта в макетах (требование ДЗ — «ключевой сценарий + ключевые проблемы»):** ближе по логике к дашборду, не «соцсеть/маркетплейс». Покажем три экрана, каждый закрывает одну из трёх главных болей из исследования.

**Референсы стиля:**
- `cyberroom.fortis.ru` — B2B-tech, тёмный фон, технологичный, два больших блока с формой захвата лида, FAQ внизу, плотные карточки фич.
- `locospadel.ru` — чёткие тарифы по табам, повторяющийся CTA, подача через выгоды.

## 1. Цели лендинга

1. **Главная цель:** заявка на trial / запись в waitlist (lead capture). Это и метрика для защиты инвестору.
2. **Вторичная:** объяснить ценность за 10 секунд скролла — «единое рабочее пространство для ментора + AI берёт рутину».
3. **Третичная:** дать инвесторскому комитету материал для оценки готовности продукта.

**Воронка лендинга:**
```
Hero (эмоциональный hook) → Проблема (узнавание) → Решение (3 фичи) →
Макеты продукта (доверие) → Для кого (квалификация) → Тарифы (решение) →
Социальные доказательства → FAQ (снятие возражений) → Финальный CTA
```

## 2. ЦА и тон голоса

**ЦА:** активные IT-менторы (backend / frontend / data / devops / PM / дизайн), 5–10 учеников, доход 60–150 K ₽/мес от менторства, уже платят за Notion/ClickUp.

**Tone of voice:**
- На «ты», но профессионально (как Linear, Notion, Vercel — не «купите наш продукт»).
- Язык результата, а не фич: «веди в 2× больше учеников», а не «AI-генерация фидбека».
- Конкретика и цифры (минуты, проценты, рубли) — техническая аудитория верит данным.
- Без маркетингового мусора («революционный», «инновационный»).

## 3. Технологический стек

Python-первый, как просил пользователь. Лендинг — статика по сути, но Flask даёт нам Jinja-партиалы (DRY-блоки), серверный endpoint для формы заявки и удобный dev-сервер с hot reload.

| Слой | Выбор | Причина |
|---|---|---|
| Бэкенд | **Flask** + Jinja2 | минимально, Python, есть шаблонизация |
| Стили | **Tailwind CSS** (CDN на dev, build для prod) | быстро, тёмная тема из коробки, не пишем CSS вручную |
| Иконки | **Lucide** (через CDN) | open-source, технологичный look |
| Шрифты | **Inter** + **JetBrains Mono** | стандарт для tech-SaaS, узнаваемо |
| Анимации | Framer-motion-style на CSS + чуть-чуть Alpine.js | достаточно для landing, без React |
| Форма заявки | POST `/api/lead` → JSON-файл `leads.json` (для демо) | не разворачиваем БД ради ДЗ |
| Конфиг | `.env` через `python-dotenv` | пароли/секреты не в коде |
| Зависимости | `requirements.txt` + `venv` | стандарт Python |
| Запуск | `python app.py` или `flask run` | одна команда |

**Почему не чистый HTML/Vite/Next:** пользователь явно сказал «Python preferably». Flask — самый простой способ остаться в Python-мире без оверкилла на Django.

**Почему не Streamlit:** это не дашборд. Лендинг с уникальным дизайном на Streamlit делать дольше, чем на Flask + Tailwind.

## 6. Контент каждого блока

### 6.1. Nav
- Слева: логотип `MentorTrack` + wordmark.
- По центру: ссылки `Возможности · Тарифы · Для кого · FAQ`.
- Справа: `Войти` (text-link) + `Попробовать бесплатно` (primary button).
- Sticky, blur-фон при скролле.

### 6.2. Hero
- **H1:** «Веди в 2× больше учеников. Без выгорания.»
- **Sub:** «MentorTrack — единое рабочее пространство для индивидуального ментора. AI пишет черновики фидбека, замечает пропавших учеников и собирает контекст к каждой встрече за тебя.»
- **Primary CTA:** `Попробовать 14 дней бесплатно` (без карты).
- **Secondary:** `Посмотреть демо` (scroll к макетам).
- **Под кнопками:** «Без карты · Импорт из Notion за 5 минут · 1 строка кода — нет».
- **Визуал справа:** скриншот дашборда (мок), частично уходящий за правый край (как у Linear / Vercel).

### 6.3. Боль — «Знакомо?»
Заголовок: «Если ведёшь 5+ учеников — узнаешь.»

3 карточки (icon + title + body), цифры — из исследования (HW_5_ProdStd.txt):

1. **Хаос инструментов** — «Notion + таблицы + Telegram + Zoom. 87% менторов держат 3–5 инструментов одновременно.»
2. **Потолок 10 учеников** — «Каждый ученик — 30–60 минут на фидбек в неделю. На 7-м начинается выгорание.»
3. **Пропавшие ученики** — «Заметил, что Маша молчит уже 2 недели — а она уже ушла. И ты потерял 15 000 ₽/мес.»

### 6.4. Решение
Заголовок: «Одно место. AI берёт рутину. Ты — финальное слово.»

3 фичи в крупных карточках с скриншотами:

1. **Единый профиль ученика** — цели, план, история встреч, ДЗ. Без переключения вкладок.
2. **AI-черновик фидбека** — загружаешь ДЗ → получаешь черновик за 30 сек → правишь, отправляешь.
3. **Проактивный мониторинг** — алёрт, когда ученик пропустил 2 ДЗ или активность упала на 50%.

Каждая карточка ссылается на боль из 6.3 («Решает: пропавших учеников»).

### 6.5. Макеты продукта (обязательный блок ДЗ) — см. §7

### 6.6. Как это работает
Горизонтальная лента из 4 шагов:

1. **Импорт** — подключаешь Notion / Google Sheets, MentorTrack вытягивает учеников и историю.
2. **AI-план** — заполняешь анкету ученика → AI собирает индивидуальный план обучения.
3. **Работа** — ведёшь встречи, AI готовит pre-meeting summary, после встречи — черновик фидбека.
4. **Контроль** — дашборд показывает, кто рискует уйти. Ты вмешиваешься заранее.

### 6.7. Для кого
3 портрета (карточки):

- **Активный ментор** (5–10 учеников, 60–150 K ₽/мес) — приоритетный сегмент. «Ты упёрся в потолок времени.»
- **Эксперт** (10+ учеников, мини-школа) — «Тебе нужна аналитика и Team-тариф.»
- **Новичок** (1–4 ученика) — «Стартуешь — Starter за 1 490 ₽ выгоднее, чем 5 разных подписок.»

## 7. Блок «Макеты продукта» — детально

**Требование ДЗ:** показать ключевой сценарий + ключевые проблемы. Делаем 3 экрана = 3 шага одного сценария «ментор готовится к недельной волне фидбека».

Каждый экран — мок-UI в HTML/CSS (никакой Figma не нужно, рендерим как `<div>` с тенью, чтобы выглядело как скрин). Это и быстрее, и адаптивно, и можно править прямо в коде.

| # | Экран | Сценарий | Какую боль закрывает |
|---|---|---|---|
| 1 | **Дашборд менторa** | «Утром понедельника вижу всех 8 учеников: у Маши — алерт ⚠️, у Пети — 2 невыполненных ДЗ» | Пропавшие ученики + хаос инструментов |
| 2 | **Карточка ученика + AI-черновик фидбека** | «Открываю ДЗ Алексея, MentorTrack уже сгенерил черновик: 4 абзаца — оставляю 3, правлю 1» | Ручной фидбек (30–60 мин → 5 мин) |
| 3 | **AI-план обучения нового ученика** | «Заполняю анкету Кати → MentorTrack за 20 сек собирает 12-недельный план с темами и ДЗ» | Онбординг (2–4 ч → 5 мин) |

**Реализация мок-экранов:**
- Тёмная тема, browser-frame (3 кружочка слева сверху + URL bar `app.mentortrack.io`).
- Реальные имена из HW_5 (Алексей, Мария, Дмитрий, Маша) — не lorem ipsum, чтобы выглядело живо.
- Цвета алертов: красный для дропаута, зелёный для ok, жёлтый для риска.
- Под каждым моком — подпись: «Решает: <боль>».

Делаем pure CSS, без картинок. Альтернатива — нагенерить png-скриншоты, но это лишняя работа и хуже скейлится.

**Требование ДЗ:** реальная цена + модель покупки + элементы, подталкивающие к решению.

**Структура:**

- **3 карточки** (Starter / Pro / Team), Pro выделен (бордер + бейдж «Популярный»).
- **Под карточками:** микро-FAQ: «Можно сменить тариф в любой момент · Без скрытых платежей · Возврат за неиспользованные дни».
- **Финальный аккорд:** «Один новый ученик = 15 000 ₽/мес. Pro окупается за неделю.»

**Карточки:**

```
└───────────────┘  └────────────────────┘  └─────────────┘
```

**Decision-driving элементы:**
1. **Бейдж «Популярный»** на Pro (90% подписок туда → social proof + anchoring).
2. **Зачёркнутая годовая цена** при toggle на «Год» — `3 588 ₽/мес ~~2 990 ₽~~ → 2 392 ₽/мес`.
3. **«14 дней бесплатно, без карты»** под кнопкой каждого тарифа — снимает страх.
4. **«Один новый ученик окупает Pro за 1 неделю»** — ROI-аргумент из исследования (медианная WTP 2–3 K).
5. **Гарантия возврата** — снижает риск решения.
6. **Контактный CTA на Team** (`Связаться`) — sales-handoff на B2B.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python app.py            # http://localhost:5000
```

### 10.4. app.py — общий каркас

- `GET /` → render `index.html`.
- `POST /api/lead` → принимает `{email, plan?, source?}`, дописывает в `leads.json` с timestamp, возвращает `{ok: true}`.
- 404-страница (опционально).

## 11.5. Хостинг — где и как деплоим

### Рекомендуемый путь (по умолчанию): **Render.com — Web Service (free tier)**

**Почему Render:**
- Бесплатный план для Flask, никакой кредитки.
- `git push` → автодеплой, как Vercel, но для Python нативно.
- Даёт публичный HTTPS-домен `mentortrack.onrender.com` сразу.
- Free-tier «засыпает» через 15 мин неактивности (cold start ~30 сек) — для защиты инвесторам это не страшно: один раз прогрел перед демо и работает.
- Конфиг — один файл `render.yaml`, минимально.

**Что нужно:**
1. Положить код на GitHub (новый публичный или приватный репо).
2. Зарегистрироваться на render.com через GitHub.
3. Добавить файл `render.yaml`:

   ```yaml
   services:
     - type: web
       name: mentortrack-landing
       runtime: python
       buildCommand: pip install -r requirements.txt
       startCommand: gunicorn app:app
       envVars:
         - key: SECRET_KEY
           generateValue: true
         - key: FLASK_ENV
           value: production
   ```
4. Добавить `gunicorn==21.2.0` в `requirements.txt` (Flask dev-сервер для prod не подходит).
5. На Render: New → Web Service → подключить репозиторий → Deploy.

**Хранилище лидов в prod:** `leads.json` на free-tier эфемерный (стирается при рестарте). Варианты:
- **Минимум для ДЗ:** оставить JSON, лиды живут до cold-start. Достаточно для демо.
- **Адекватнее:** при заявке слать в Telegram-бот через `requests.post` к Bot API → `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в env. Никакой БД не надо.
- **Серьёзнее:** Render PostgreSQL (free 90 дней) или Supabase Postgres (free навсегда).

### Альтернативы (если что-то не подойдёт)

| Платформа | Плюсы | Минусы | Когда выбирать |
|---|---|---|---|
| **Render** ⭐ | бесплатно, простой Python, autodeploy | cold start на free | дефолт, для ДЗ |
| **Railway** | $5 кредит/мес, без cold-start, мощный CLI | бесплатность ограничена кредитом | если нужен «всегда тёплый» сервер |
| **Fly.io** | реально бесплатные small VMs, edge | сложнее на старте, нужен Dockerfile | для тех, кто любит контейнеры |
| **PythonAnywhere** | специально для Python, без билдов | устаревший UI, медленный | для совсем простых демо |
| **Vercel** | мгновенный CDN, идеален для статики | Flask только через serverless-обёртку, неудобно | если перепишем на статику без Flask |
| **GitHub Pages** | бесплатно навсегда, надёжно | только статика — Flask не запустится | если откажемся от Python-бэкенда |
| **VDS (Reg.ru / Timeweb / Selectel)** | полный контроль, ~200 ₽/мес | надо настраивать nginx, certbot, systemd | для prod с реальным трафиком |

### Доменное имя

- **Для ДЗ-защиты:** хватит `mentortrack.onrender.com`.
- **Если хочется красиво:** `.ru` за ~199 ₽/год на reg.ru или `.io` за ~$35/год на Namecheap. Подключение к Render — добавить CNAME, 5 минут.

### Финальная рекомендация

**Для защиты ДЗ инвесторам:**
1. Закидываем код на GitHub.
2. Деплоим на Render free-tier.
3. Лиды → Telegram-бот команды (моментальное уведомление, не теряем заявки).
4. За 30 минут до защиты пингуем URL, чтобы прогрелся cold-start.

Всё остальное (домен, БД, аналитика) — после ДЗ, если продукт пойдёт дальше.
